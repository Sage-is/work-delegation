# Uploading Documents

It should be noted that the process of uploading documents to the system is
actually quite straightforward and simple. In order to begin the process of
uploading, users will first need to navigate their way to the admin panel,
which can basically be found in the upper right-hand corner of the interface.
Once the user has successfully arrived at the admin panel, there is a button
labeled "Upload" that can be clicked in order to initiate the commencement of
the upload process. It is important to note that the system is capable of
supporting a wide variety of different file formats, including but not limited
to PDF, DOCX, and TXT. In the event that an upload happens to fail for any
reason whatsoever, users are advised to attempt the upload again at a later
point in time.
